# Проект: Аналитика задач таск-трекера

## Описание
Веб-приложение для анализа закрытых задач в таск-трекере (аналог Jira). Основной функционал:
- Загрузка CSV-файлов (Эпики, Истории, Задачи).
- Построение связей Эпик → Истории → Задачи.
- Привязка задач к участникам команды.
- Расчет количества закрытых задач и очков по участникам команды.
- Построение графиков аналитики.

## Используемые технологии
- **Backend**: Flask (Python 3)
- **База данных**: SQLAlchemy (с возможностью использовать SQLite или PostgreSQL)
- **Анализ данных**: Pandas
- **Frontend**: HTML, CSS, Bootstrap
- **Графики**: Plotly (или Chart.js для интерактивной визуализации)
- **Контейнеризация**: Docker, Docker Compose

## Развертывание
1. Собрать Docker-образ:
   ```bash
   docker-compose build
   ```
2. Запустить контейнер:
   ```bash
   docker-compose up
   ```
3. Приложение будет доступно по адресу [http://localhost:80](http://localhost:80).
